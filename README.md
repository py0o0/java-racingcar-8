# 자동차 경주

## 기능 요구사항
- 사용자는 자동차의 이름을 부여할 수 있다.
  - 자동차의 이름은 `,`를 기준으로 한다.
  - 자동차의 이름은 공백이 허용되지 않는다.
  - 자동차의 이름은 중복이 허용되지 않는다.
  - 자동차의 이름은 5자 이내여야 한다.
  
- 사용자는 시도 횟수를 입력할 수 있다.
  - 1 이상의 숫자만 가능하다.
  
- 자동차는 시도 횟수만큼 전진한다.
  - 단, 0~9중 랜덤한 값이 4 이상이 나와야 전진할 수 있다.
  
- 경주를 마친 후, 우승자를 발표한다.
  - 우승자는 여러 명일 수 있다.
